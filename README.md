# Mini Agent Runtime

A local AI coding agent runtime built from scratch to explore the core engineering ideas behind modern coding agents.

## Goals

This project is built as a hands-on exploration of:

- Agent loops
- Tool calling
- Task planning
- Event-driven execution
- Session and context management
- Permission control
- Sub-agents and MCP integration

## Project Status

🚧 Currently under active development.

## Inspiration

This project is inspired by modern coding agents such as Claude Code and the open-source KamaClaude project.

The implementation is being developed step by step for learning, experimentation, and engineering practice.
